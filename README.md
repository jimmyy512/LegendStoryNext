## 執行

建議使用 Node.js 24，本次驗證使用 24.18.0。

```sh
npm ci
npm run dev
```

開啟 http://127.0.0.1:5173/ 。正式版本使用 `npm run build`，將 `dist/` 放到靜態網站服務。

## 目前原型

戰鬥試玩： http://127.0.0.1:5173/?preview=combat ，使用記憶體存檔，不讀寫正式旅程。雙方皆為 10 級，我方滿血滿內力，敵人採偏重生命的演武成長，保留較長的交鋒時間。加上 `&route=fist&enemies=two` 可測拳掌對雙敵人。先用貼近對手／保持射程／拉開距離／停步回氣決定站位，再按開始交鋒；點招式會預約下一擊並繼續交鋒。操作區會直接提示雙方是否在射程內。A／D 可微調目標距離，空白鍵暫停。招式起手後退出射程會落空，內力不退還。

地圖角色動作預覽：`?preview=world&map=temple`，使用記憶體存檔直接進入門派；也可把 `map` 改成 `forest`、`mountain` 或 `cave`。此入口用來檢查 NPC 和地圖敵人的姿勢與站位。

試玩預設為已裝備武器與道袍的試招戰；`&enemies=boss` 可挑戰首領，`&map=forest|temple|mountain|cave` 可檢查四張戰鬥背景。正式探索與戰鬥共用分層像素女俠，武器、衣甲、髮型與右手傷勢由遊戲狀態帶入。四類敵人及五名門派 NPC 已改用獨立像素圖，四招使用各自的原創程式像素特效；敵人目前仍以單張圖做程式動態，尚未完成逐格或骨架動作。雙方人形圖紅色代表受傷、黑色代表損毀，點敵方部位選擇攻擊位置，點我方部位查看傷勢。一般防禦消耗 20 腳力並立即減傷，招式則預約下次出手。

- 松風林、全真派、全真後山、禁地山洞四個地區。
- 點擊尋路、人物對話、一條主線、兩條支線、善意／武力分支。
- 劍法／拳掌、四個招式、兩種內功、獨立半即時戰鬥與戰術暫停。
- 部位傷勢、單雙手招式效能、跛行、坐地與爬行。生命藥不接骨，回門派調息可治療。
- 背包、裝備、商店、手動／自動存檔、JSON 匯出與匯入。
- 引擎啟動載入畫面、分區資源載入、失敗重試與換圖資源清理。

場景仍以程式繪製的示意地形為主，已將道路與樹木像素化；建築、岩石、物件及戰鬥背景仍需正式美術。音效目前為合成提示音，尚未完成音樂與整體聽感驗收。洛陽篇、雲端存檔與手機完整適配不在第一章範圍。15–30 分鐘是設計目標，尚未完成一般玩家的時長與趣味驗收，因此目前不能宣稱已可上線。

傷勢驗收頁： http://127.0.0.1:5173/?preview=injuries ，可直接測姿態，不讀寫旅程存檔。v1／v2 舊存檔會驗證後升為 v3，保留既有進度並補預設髮型。

角色面板可切換三種髮型與斗笠，探索外觀立即更新，選擇會保存在存檔中。

女俠降龍十八掌比較頁： http://127.0.0.1:5173/?preview=styles 。並排比較 Q 版 Spine 與像素八格動畫，支援同步播放、慢動作與時間軸。

像素女俠分層試作： http://127.0.0.1:5173/?preview=pixel-rig 。依選定的像素方向，以女俠為範本，左右同步驗證走路、出掌、換衣、換武器與右手失能後改左手出招。支援慢動作與逐格檢查，獨立於正式戰鬥。可編輯 Spine 專案及素材說明在 `art/characters/pixelHeroine/`。

原版主角預覽： http://127.0.0.1:5173/?preview=legacy 。此頁保留舊角色素材供比較；正式探索與戰鬥現已使用分層像素女俠。

持續工作項目記錄於 [第一章完成清單](docs/implementation-checklist.md)。

## 開發檢查

```sh
npm run lint
npm run format:check
npm test
npm run build
```

ESLint 檢查程式規則，Prettier 管理此 Pixi/TypeScript 專案排版。測試與編譯不能取代瀏覽器實際操作驗證。

### 滿版 Pixi 介面

正式遊戲的主選單、狀態列、探索與戰鬥操作、對話、行囊、任務、存讀檔及設定都由 Pixi 繪製。
地圖等比鋪滿可用畫面，探索鏡頭跟隨角色，附近地點可由右下方選單前往。
面板點開才顯示，長內容支援滑動，保留瀏海與系統手勢安全邊距。

全螢幕按鈕會檢查瀏覽器能力並處理拒絕情況。姓名輸入由 Pixi Input 串接原生鍵盤，
匯入與匯出沿用瀏覽器檔案功能。引擎尚未載入或 WebGL 初始化失敗時保留 HTML 救援畫面，
引擎載入後的場景切換與重試改由 Pixi 顯示。開發用 preview 頁面維持原樣。

`src/ui/canvas/` 提供面板資料結構與共用元件，`GameView` 負責場景上的介面，
`PanelView` 與 `storyPanels` 產生不依賴 DOM 的面板資料，`render/camera.ts` 管理等比例取景。
