# 口袋江湖：半即時戰鬥與部位傷勢 v0.3

本文件取代 v0.2 的傳統輪流回合戰鬥，探索與第一章故事維持原草案。

## 已確認方向

- 參考太吾繪卷的自動普攻與招式穿插節奏。
- 參考逃離塔科夫的部位傷害概念，不照抄槍械、失血與傷害傳遞公式。
- 招式依所需部位計算威力，不對整個角色一律扣攻擊力。
- 右手失能時，左手可完成的單手招式仍有 100% 威力。雙手招式剩一手可用時為 50%。
- 傷勢必須表現在角色姿態上，不呈現血液、斷肢或暴露傷口。
- 雙腿失能時坐地，仍能使用手部招式。移動改為爬行。

## 原型操作

每個角色獨立蓄勢，身法越高出手間隔越短。蓄勢滿後自動普攻，不需要每一下都按攻擊。

開場先暫停，按「開始交鋒」或空白鍵推進。玩家可隨時戰術暫停查看敵情。背景分頁、藥品面板開啟時不推進戰鬥。

點招式、防禦、藥品或撤退，會預約下一次出手並恢復時間。可替換或取消預約，真正出手才扣內力與物品。到出手時再驗證傷勢，所需部位失能則不扣資源，但消耗這次出手機會。

目前是「自動普攻、手動預約招式」，沒有自動放技能策略。選招式是否自動暫停，保留依試玩調整。

## 部位與招式

部位包含頭、胸、腹、左手、右手、左腿、右腿。四肢耐久歸零代表骨折／重傷失去功能，不代表被切除。

| 狀態 | 能力 | 表現 |
|---|---|---|
| 一手失能 | 單手招式 100%，雙手招式 50% | 傷手垂落、繃帶、健手持武器 |
| 雙手失能 | 手部招式不可用，腿可用時改弱踢擊 | 雙手垂落、不持劍 |
| 一腿失能 | 移速 55%，單腿招式可用，雙腿招式 50% | 跛行、不對稱支撐 |
| 雙腿失能 | 移速 20%，腿招不可用，手招不直接減傷 | 靜止坐地，移動爬行 |
| 四肢失能 | 戰鬥中判定無法再戰，不能移動 | 坐地 |

移速與撤退率都是原型數值。單腿失能的撤退率暫定 35%，雙腿失能不能一般撤退。目前戰場沒有距離／追擊，腿傷移速實際作用於探索，不宣稱已有戰場走位。

招式資料使用 `limbs: { hands: 0 | 1 | 2, legs: 0 | 1 | 2 }`。現在支援任一手／任一腿，尚無限定左掌、右劍或特定支撐腿的需求。

清風破甲與抱元守一需單手，落雁一劍與伏龍掌需雙手。正式腿法招式尚未加入，需求規則與測試已保留。雙手威力 50% 指防禦計算後傷害取半再四捨五入。

## 尚屬原型的規則

- 保留總生命決定戰敗。頭胸腹歸零目前只顯示重傷，沒有要害即死。
- 部位傷害按角色生命上限換算至固定耐久尺度，尚未完成平衡驗收。
- 尚無失血、疼痛、感染、護甲部位、命中率與已失能部位傷害傳遞。
- 勝利和撤退保留傷勢。生命藥與升級不接骨，回門派調息暫可免費完全治療。
- 戰敗恢復戰前消耗並治療，避免主線卡死。接骨藥、費用、永久殘疾尚未定案。

## 架構

- CombatClock：固定步長，不依顯示幀率決定戰鬥結果。
- Battle：蓄勢、自動普攻、預約指令、出手驗證與傷害事件。
- body：部位耐久、招式肢體效能、移速與姿態判斷。
- CombatantSprite：用同一份傷勢資料繪製非血腥姿態。
- BattleScene：出手位移、命中氣痕與傷害數字。
- ExplorationScene：受傷步態與爬行移速。
- Save codec：v3 保存傷勢與髮型。v1 驗證後補完好部位與預設髮型，v2 保留傷勢並補預設髮型。

規則不讀 Pixi 節點，動畫不決定傷害。替換正式骨骼動畫時仍使用相同部位資料。
