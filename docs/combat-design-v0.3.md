# 口袋江湖：半即時戰鬥與部位傷勢 v0.3

本文件取代 v0.2 的傳統輪流回合戰鬥，探索與第一章故事維持原草案。

## 已確認方向

- 參考太吾繪卷的自動普攻與招式穿插節奏。
- 參考逃離塔科夫的部位傷害概念，不照抄槍械、失血與傷害傳遞公式。
- 招式依所需部位計算威力，不對整個角色一律扣攻擊力。
- 右手失能時，左手可完成的單手招式仍有 100% 威力。雙手招式剩一手可用時為 50%。
- 傷勢必須表現在角色姿態上，不呈現血液、斷肢或暴露傷口。
- 雙腿失能時坐地，仍能使用手部招式。移動改為爬行。

## 原型操作

每個角色獨立蓄勢，身法越高出手間隔越短。蓄勢滿後自動普攻，不需要每一下都按攻擊。

開場先暫停，按「開始交鋒」或空白鍵推進。玩家可隨時戰術暫停查看敵情。背景分頁、藥品面板開啟時不推進戰鬥。

點招式、藥品或撤退，會預約下一次出手並恢復時間。可替換或取消尚未起招的預約。攻擊進入射程後才起招，此時扣內力與氣勢並鎖定目標、部位及射程；取消預約不會撤銷已起招的攻擊。命中瞬間再檢查距離和肢體效能，落空或中斷不退還已付成本。藥品在實際使用時消耗。

2026-09-22 實玩修正：一般「防禦」改為立即收勢，消耗 20 腳力，有 1 秒再使用間隔；可以中斷自己的起招，但不退還已付內力。等待擋下敵方一擊後恢復自動普攻，期間承傷為原本 40%。抱元守一仍是消耗內力的招式預約，額外提供反擊。

戰鬥 HUD 使用持續存在的雙方狀態卡與底部操作區；每次傷害不重建場景。雙方人形圖顯示七個部位：完好為灰白、受傷為紅、耐久為零為黑並加交叉線；金框獨立標示選定的攻擊部位。狀態區顯示護體、破甲、破綻與腳力耗盡。參考使用者提供的 [塔科夫健康系統](https://escapefromtarkov.fandom.com/zh/wiki/健康系統?variant=zh-tw) 的部位和狀態區分，不沿用傷害分攤、即死或醫療物品規則；中毒與持續傷害尚未實作。

清風破甲使用青色穿刺劍氣，落雁一劍使用弧形劍光，伏龍掌使用金色掌勁與氣環，抱元守一使用藍色護體。事件攜帶技能識別供特效使用，不以戰報文字猜招式。命中數字與最近戰報提供結果回饋；敵方重擊起招有紅色警示。

2026-09-23 可讀性修正：使用者反映看不懂戰鬥。HUD 加上我方出手進度條（金）與敵方蓄勢條（紅），距離列直接寫出「我打得到／太遠打不到」與「敵打得到我」。移動按鈕加副標（貼身纏鬥、站在射程內、退出敵射程、恢復腳力），距離尺圖例改為「我射程／敵射程」。操作區右上新增「？ 說明」，開啟時戰鬥暫停，六段白話規則會帶入當下武器與對手的實際射程。規則數值未改。

目前是「自動普攻、手動預約招式」，沒有自動放技能策略。選招式是否自動暫停，保留依試玩調整。

## 交鋒節奏：氣勢與破綻

2026-09-22 加入第一輪可玩規則，數值仍待試玩調整：

- 每次普攻出手與存活時成功防住一次攻擊，各累積 1 格氣勢，上限 3 格。只在本場戰鬥有效。
- 滿氣勢時，下一次攻擊招式在起招時消耗全部氣勢，招式倍率提高 35%，命中後將存活目標的蓄勢減少 50 個百分點。尚未起招的預約與取消不消耗氣勢。
- 抱元守一不消耗氣勢，可透過防守蓄勢後接伏龍掌。反擊本身不另加氣勢。
- 敵人以雙手重擊後露出破綻，下一次受到玩家命中時，防禦計算後傷害提高 35%。命中後消失，若未被命中則在敵人下次出手時收回。反擊也能利用破綻。
- 氣勢爆發與追擊可疊加，肢體效能仍於最後計算，保留單手／雙手傷勢規則。
- HUD 即時顯示玩家出手進度、三格氣勢、各敵人的蓄勢百分比與意圖。攻擊招式滿氣勢時標示「爆發」。

目標是讓玩家能選擇立即用招、普攻蓄勢、先防守再追擊，或用爆發延後危險敵人的出手。仍採預約制，防禦需等自己出手才生效。

## 部位與招式規則

部位包含頭、胸、腹、左手、右手、左腿、右腿。四肢耐久歸零代表骨折／重傷失去功能，不代表被切除。

| 狀態 | 能力 | 表現 |
|---|---|---|
| 一手失能 | 單手招式 100%，雙手招式 50% | 傷手垂落、繃帶、健手持武器 |
| 雙手失能 | 手部招式不可用，腿可用時改弱踢擊 | 雙手垂落、不持劍 |
| 一腿失能 | 移速 55%，單腿招式可用，雙腿招式 50% | 跛行、不對稱支撐 |
| 雙腿失能 | 移速 20%，腿招不可用，手招不直接減傷 | 靜止坐地，移動爬行 |
| 四肢失能 | 戰鬥中判定無法再戰，不能移動 | 坐地 |

移速與撤退率都是原型數值。單腿失能的撤退率暫定 35%，雙腿失能不能一般撤退。腿傷效能已同時作用於探索和戰場追近／退避。戰場位移另外受到腳力、起招及收招限制；停步可恢復腳力。

招式資料使用 `limbs: { hands: 0 | 1 | 2, legs: 0 | 1 | 2 }`。現在支援任一手／任一腿，尚無限定左掌、右劍或特定支撐腿的需求。

清風破甲與抱元守一需單手，落雁一劍與伏龍掌需雙手。正式腿法招式尚未加入，需求規則與測試已保留。雙手威力 50% 指防禦計算後傷害取半再四捨五入。

## 尚屬原型的規則

- 保留總生命決定戰敗。頭胸腹歸零目前只顯示重傷，沒有要害即死。
- 部位傷害按角色生命上限換算至固定耐久尺度，尚未完成平衡驗收。
- 尚無失血、疼痛、感染、護甲部位、命中率與已失能部位傷害傳遞。
- 勝利和撤退保留傷勢。生命藥與升級不接骨，回門派調息暫可免費完全治療。
- 戰敗恢復戰前消耗並治療，避免主線卡死。接骨藥、費用、永久殘疾尚未定案。

## 架構

- CombatClock：固定步長，不依顯示幀率決定戰鬥結果。
- Battle：蓄勢、自動普攻、預約指令、出手驗證與傷害事件。
- body：部位耐久、招式肢體效能、移速與姿態判斷。
- CombatantSprite：用同一份傷勢資料繪製非血腥姿態。
- BattleScene：出手位移、命中氣痕與傷害數字。
- ExplorationScene：受傷步態與爬行移速。
- Save codec：v3 保存傷勢與髮型。v1 驗證後補完好部位與預設髮型，v2 保留傷勢並補預設髮型。

規則不讀 Pixi 節點，動畫不決定傷害。替換正式骨骼動畫時仍使用相同部位資料。
