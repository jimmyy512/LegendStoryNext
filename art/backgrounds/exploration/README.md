# 第一章探索地圖

目前使用 `source/*-stylized.png`。此版本以主角的粗像素輪廓與大色塊為準，降低寫實碎紋，並統一八張探索／戰鬥背景的青松、暖土與灰石配色。原始 `source/*.png` 保留作構圖參照，不再輸出到遊戲。輸出使用 nearest 重採樣，避免邊緣模糊。

`source/*.png` 為四張原創探索地圖母圖。每張以同地點的戰鬥背景作為像素風格與配色參考，重新繪製成可行走的俯視地圖；不是把側視戰鬥背景直接套到探索畫面。主路、分支路、門派建築、山崖、洞穴水域與互動物件皆在各自地圖內繪製。

`python tools/buildExplorationMaps.py` 會輸出 1152×720 WebP 到 `public/assets/backgrounds/exploration/`。遊戲只載入 WebP，PNG 留作後續美術修訂。

美術方向：清楚可辨的可走路徑；松風林深青松樹與暖土路、全真派青瓦石院、後山石徑與雲崖、藏霧洞青綠水域與暖燈。無人物、UI 或文字。新地圖製作時必須同步核對 `src/data/maps.ts` 的互動座標、出生點及可走格，不能只替換背景圖。
