# 主角紙娃娃樣板

本目錄改作 Spine 技術驗證。正式主角優先沿用 `../legacyHero/` 的原版素材，不以本 AI 人物作為美術定案。

## 第一批驗收範圍

兩套服裝、兩種髮型、兩把劍。先驗證正面／微側面的戰鬥角色，不宣稱已完成探索的四向或八向素材。

動作依序為待機、走路、右手揮劍、左手揮劍、受擊、右手失能、跛行、坐地與爬行。手部失能不使用斷肢或血液表現。

## 部件命名

左右一律指角色本人的左右，不是觀看者左右。骨架保留 `root`、`pelvis`、`torso`、`head`、`upperArmL/R`、`forearmL/R`、`handL/R`、`thighL/R`、`shinL/R`、`footL/R` 與 `weaponL/R`。

衣服 Skin 覆蓋軀幹與雙側袖子。髮型與武器為獨立 Skin，不為每種衣服髮型武器組合建立一個整套角色。換 Skin 後重設插槽，再重新套用目前動畫與傷勢。

左右手武器插槽共用武器圖片，但握點與角度分開定義。切換健手必須同時切換攻擊動畫，不能只把劍搬過去。

頭髮有前後遮擋層。第一批袖子、鞋與腿部素材仍需檢查左右鏡像是否合理，不能把帶方向性的裝飾直接鏡像當成正式素材。

## 驗收清單

- [x] 原始圖片與完整生成提示保存在遊戲 repository。
- [ ] 獨立拆件 PNG，透明邊緣乾淨，肩肘膝接縫不露空。
- [x] `.spine` 原始專案可從 repository 的相對路徑找到圖片，已透過 CLI 匯出圖集驗證。
- [ ] 服裝、髮型、武器任意組合都能顯示。
- [ ] 武器握點在左右手攻擊時不漂移。
- [ ] 傷手垂落時袖子與手一起動，不再播放該手出招。
- [ ] 雙腿失能坐地／爬行，不發生身體穿地與衣服破洞。
- [ ] 匯出資料與 Pixi runtime 版本配對，遊戲中無缺圖。
- [ ] 遊戲換裝與存讀檔整合。預覽成功不等於本項完成。

## 版本與原始檔

已建立真正的 `spine/hero.spine`，使用 editor 4.3.26、runtime 4.3.13。`hero-source.json` 是初始骨架來源，已經過官方 editor 匯入及再次匯出，不是改副檔名。

預覽網址：`http://127.0.0.1:5173/?preview=spine`。含待機、走路、左右手揮劍、受擊、傷手覆蓋姿態與坐地。尚無正式爬行、跛行或四向探索動畫。

目前採 FK 關鍵影格，未加入網格、IK 或布料物理。素材品質仍是樣板，不能宣稱完成正式角色製作。

重匯出命令（repository 根目錄）：

```sh
/Applications/Spine.app/Contents/MacOS/Spine -u 4.3.26 \
  -i art/characters/hero/spine/hero.spine \
  -o public/assets/characters/hero -e json+pack
```

Spine 匯入後請以 `.spine` 為人工編輯來源。不要拿初始 `hero-source.json` 覆蓋後續人工調整的專案。

參考：[Spine Pixi 整合與版本要求](https://en.esotericsoftware.com/spine-pixi)、[可匯入的 JSON 格式](https://esotericsoftware.com/spine-json-format)。
